# Radhika Collection Studio

Build the complete production-style Radhika Collection women’s ethnic fashion e-commerce demo described by the user. Strictly use React + Vite + Tailwind and standard React/HTML/CSS/JS only: no backend, database, APIs, external UI/component libraries, Redux/Zustand, Firebase/Supabase. Use shared in-memory React state and organized mock-data modules so admin changes update the public storefront during the browser session. Implement all requested public routes, full responsive storefront, 24+ realistic INR products, functional cart/wishlist/search/filter/sort/product detail/checkout demo, and the complete responsive admin login/dashboard/management modules. Use only relevant Indian women’s ethnic fashion imagery that render correctly, premium maroon/cream/blush/champagne-gold visual system, polished mobile experience, and ensure navigation/buttons/error states work without broken links or console errors. Include the requested business details and footer Admin Login link to /admin/login.
